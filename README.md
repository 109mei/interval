# INTERVAL — 糧と期限の盤（試作）

独自4駒を期間契約で召喚する、7×7のターン制ゲームです。ローカル2人対戦と基本CPU戦を実装しています。白黒の立体駒はThree.jsで描画し、WebGLが使えなければ2Dへ切り替えます。

## 遊び方
- 敵の固定コア（◆）へ攻撃可能な駒を移動させれば勝利。
- 毎手番に糧4。保有上限はありません。初期12に初回収入を加え、各側の初手は16。
- 自陣の手前2列の空きマスに、期間1〜5で召喚。費用は単価×期間を前払い。
- 1手番に召喚、移動、交換、パスから1行動。パスも選択後に確定を押します（連打による誤操作を防ぐため）。
- 召喚した番はその駒の期間を減らしません。以後は自分の手番末に自軍全駒を1減らし、0で退場。動かなかった駒も減ります。
- 捕獲報酬は、取った敵の単価×捕獲時の残り期間。自然退場では獲得しません。
- コア捕獲は期限処理より優先。連続6パスまたは200手で引き分け。
- バスティオン（単価1）: 動かない壁。リンクで交換できる。
- カーヴァー（単価3）: 縦横1マスから直角に1〜2マス。途中に駒がある経路は不可。
- リーパー（単価2）: 隣接する駒を8方向に飛び越え、直後へ着地。足場は残し、着地点の敵だけ取る。
- リンク（単価1）: 縦横に隣接する味方と位置交換。捕獲は不可。期限を延長しない。

## 実行
Node.js24以降で npm ci、npm run dev。表示されたローカルURLをブラウザーで開きます。
npm run build で dist を生成します。別配布の単体HTMLは外部通信なしで開けるように同じビルドをまとめたものです。
開始画面の「CPU対戦」で白を操作できます。CPUは基本的な1手読みと直後のコア捕獲回避であり、強い対戦AIや公平なゲームバランスを保証しません。
再読み込みで対局は終了します。アカウント、保存、オンライン対戦、解析送信、課金はありません。

## 検証
