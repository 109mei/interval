2026-10-08。既存のルールとビジュアル方針を保ちながら、再現可能な自動検証と画面評価で UI・UX、CPU の障害復帰、駒モデルを改善した記録です。

## 件数と証拠の種類

統合実行は **3,247 / 3,247 成功、25 ファイル、失敗・未実行 0**。TypeScript とクライアント／Worker の本番ビルドも成功しました。既存の 500KB 超バンドル警告は残ります。独立したレビューで UI、CPU 復帰、モデル、件数の扱いを再確認し、レビュー範囲内の未解決の重大な指摘はありません。

## 評価で見つけて修正した点

### 選択・支払い

- 公開版のクラウドブラウザ（510 × 757、2D）では、駒と期間を選んだ時に費用が長い説明の下にあり、画面下端で切れていました。費用と購入後の残高を期間ボタンの横にも配置し、糧不足なら不足額を表示します。
- 選択解除の実測高さは 32px。最小 44 × 44px にしました。
- 召喚する駒の選択状態は CSS だけでした。各選択ボタンに aria-pressed を反映します。
- 費用・残高は選択だけでは支出せず、最終確認時に一度だけ確定する契約を維持します。
- 公開後の再評価で、3D に切り替えられない理由が一般的な「2D表示」に上書きされることを確認。追加の失敗テストから修正し、「立体表示を利用できないため切り替えました」を保持します。描画中の後発エラーで切替ボタンが逆の表示になる問題も独立レビューで再現し、修正しました。この追加 2 件を含めて 3,039 件です。

### CPU の障害復帰

Worker が null または不正な手を返すと、Worker と時間切れ処理だけが終了し、黒の番で止まる経路を再現しました。現在の状態に合法な返答だけを採用し、それ以外は従来と同じローカル探索で復帰します。古い対局・重複返答は先に棄却します。探索の重みやルールは変更していません。

### 駒モデル

- バスティオン: 面取りした城壁・胸壁と装飾帯
- カーヴァー: 盤に収まる高さと、両陣営で読める湾曲した刃
- リーパー: はみ出しを抑えた鼻先、対の耳・目、控えめなたてがみ
- リンク: 両向きで輪を認識しやすい角度
- コア: 水晶と台座を分けて見せる装飾
- 台座と胴体の接続、全パーツの名前、独立したリソース所有、過度に鏡面化しない材質を整理
- リーパーのゼロ面積三角形 32 枚を除去

最初のモデル案は 400 チェックを通過しましたが、実メッシュのソフトウェア比較画像で黒カーヴァーの刃が横棒のように潰れることを確認しました。刃だけの投影高さと輪の向きを既存の投影ケースに加え、中間版で失敗することを確認してから修正しました。修正版の白黒・盤カメラ・真上・斜めの画像を再評価しました。これは自動チェックだけで見た目を承認しないための追加段階です。

描画コストは一律に下がっていません。リーパーは細部の追加で 7 → 11 メッシュ、2,432 → 3,240 三角形。リンクは 2,272 → 1,856 三角形へ減少しました。各モデルは上限 18 メッシュ・5,000 三角形・200KB のバッファ契約内です。GPU のフレーム時間は別途未検証です。

## 再現方法

```sh
QUALITY_LEDGER_DIR=/tmp/interval-final-ledgers npm test -- --reporter=default --reporter=json --outputFile=/tmp/interval-final-vitest.json
npm run build
```

各ケースは `tests/quality-*.test.ts` と `tests/quality/` にあります。ケース別の入力、検証契約、passed / failed / not-run、所要時間を rules.json、interactions.json、models.json、clarity.json に出力します。絞り込み実行では未実行ケースを成功として扱いません。Vitest の全体結果と併せて確認してください。

## 検証の限界

実 GPU の質感・影・フレームレート、物理タッチ、厳密な 390 × 844 画面、独立した 2 プロファイルによる本番フレンド対戦、支援技術の実際の音声読み上げ、実在プレイヤーの楽しさは未検証です。公開ブラウザの画像や計測と、DOM・CPU 投影・通信モックの結果を分けて扱います。部屋の作成制限や既存のアクセス制限を回避していません。

盤、4 駒のルール、単価、期間、捕獲価値、糧の上限なし、CPU 戦略、通信 API、DB スキーマ、公開先は維持しています。追加の有料サービス、API、購入アセットは使っていません。
